# --no-deps, and the block below stands in for the dependencies it declares.

# chunkformer's dependencies, hand-picked.
#
# chunkformer declares deepspeed>=0.14.0, which ships source-only and has to be
# compiled. There is no Windows wheel, and its build backend imports torch from
# an isolated build env that does not have it, so `pip install chunkformer`
# fails outright on Windows. deepspeed is a training dependency: nothing on the
# path this app uses — ChunkFormerModel.from_pretrained + endless_decode —
# imports it.
#
# So the build installs chunkformer with --no-deps and names its real imports
# here. This list was derived by importing ChunkFormerModel against an empty
# environment and adding whatever it asked for, so it is exactly what the
# inference path needs and nothing more. Dropped along with deepspeed:
# tensorboard, tensorboardX, textgrid, sentencepiece, Pillow, colorama.
#
# Because we now own that list, chunkformer itself is pinned — an unpinned
# upgrade could start importing something and would fail at runtime, inside the
# shipped installer, rather than at build time.
jiwer>=2.3.0
pandas>=1.3.0
pydub>=0.25.0
PyYAML>=5.4.0
transformers>=4.20.0
